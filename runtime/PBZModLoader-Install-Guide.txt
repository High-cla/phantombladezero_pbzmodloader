PBZModLoader: install guide
This is the KintaroModding fork of PBZModLoader by LKF: https://github.com/KintaroModding/phantombladezero_pbzmodloader

INSTALL
The easiest way: install it with one click in the mod manager UE MM: https://github.com/KintaroModding/uemodmanager

To install by hand:
1. Close the game. Open its install folder, the one that holds ProjectPBZ.
2. Look next to the real game exe (platform\steam or platform\wegame). If another tool already has a version.dll
   there, do not overwrite it: see ANOTHER ENTRY below.
3. For the default entry, copy ProjectPBZ into the install folder, and version.dll from the matching platform folder next to the game exe.
   If version.dll belongs to another tool, copy only ProjectPBZ and follow ANOTHER ENTRY below. Do not copy the packaged version.dll.
   Correct: D:\Games\PBZ\ProjectPBZ. Wrong: D:\Games\PBZ\PBZModLoader\ProjectPBZ.
4. Start the game from its platform as usual. You need no Node.js, no compiler and no UE4SS.

WHAT GOES INTO THE GAME
- version.dll next to the game exe: the loader, with its scripts inside.
- ProjectPBZ\Content\JavaScript\PBZModLoader\bootstrap.js: the start file. The DLL puts its scripts in place of its content.
  Do not edit or delete it.
- ProjectPBZ\PBZModLoader\LICENSES.txt: the license texts.
- ProjectPBZ\PBZModLoader\mods\: your mods.
While it runs, the loader writes one file: ProjectPBZ\PBZModLoader\loader.log. It starts new with each game start.

MODS
- Put the whole mod folder into ProjectPBZ\PBZModLoader\mods, for example mods\my-mod\main.js. The folder name is the mod's ID:
  English letters, digits, _ or - only. New mods are found by themselves.
- A mod must ship JavaScript. A mod with only main.ts does not run, and loader.log says so. Authors compile TypeScript with the
  developer package.
- Pak mods that change game scripts work too: keep them in ProjectPBZ\Content\Paks\~mods. They need no other tool.

MODS MENU
Mods Menu 0.9.0 or later runs beside this loader. Install it by hand from its own page. It needs this loader's start file:
without it, Mods Menu stays off. With both, Mods Menu starts its mods first, then this loader starts the mods in its own folder.
Older Mods Menu versions conflict with this loader. Mods Menu uses hid.dll, so do not use this loader's hid entry next to it.

SETTINGS (optional)
Without ProjectPBZ\PBZModLoader\mods.ini, every mod loads. Create the file only to change something:
    [Loader]
    Version=1
    ; 0 turns the whole loader off.
    Enabled=1
    ; 0 refuses pak mods that change game scripts.
    AllowScriptPaks=1
    [Mods]
    ; my-mod=0 turns one mod off.

RELOAD WHILE PLAYING (Alt+F5)
Save your files, return to the game and press Alt+F5. A message shows at the top left for about four seconds.
The loader applies changes to its JavaScript mod list and [Mods] settings, including additions and removals. Pak and UE4SS mods are not reloaded.
A mod must export stop() and clear its timers and unsubscribe from events there. If stop() is missing or fails, the existing instance is retained
and its replacement is not loaded. A mod that failed at startup is not tried again until the next game start.
The log line "reload complete" means the reload attempt finished. Check individual mod results for failures or skipped reloads.
After about 4000 reloads, restart the game.

ANOTHER ENTRY
If another tool holds version.dll, keep it. In this zip, alternative-entries holds one folder each for hid.dll, winmm.dll, dsound.dll and dxgi.dll.
Do not extract that folder into the game. Take one DLL, keep its name, and put it next to the game exe. Install only one entry of this loader. A DLL file
name that is free does not prove that the game loads it early enough: if no new loader.log is created or it stays empty, try another one.
Before switching, close the game and remove the previously selected loader DLL. Keep other tools' DLLs.

UPDATE FROM VERSION 2.0.x
Close the game, replace the DLL and LICENSES.txt, and add the start file: copy ProjectPBZ into the install folder as above.
Keep ProjectPBZ\PBZModLoader\mods\ and your mods.ini.

UPDATE FROM VERSION 1.0.x
Do the same, then delete what the old version left, all of it safe to remove:
    ProjectPBZ\Content\JavaScript\PBZModLoader\manager.js
    ProjectPBZ\Content\JavaScript\PBZModLoader\generated-config.js
    ProjectPBZ\Content\JavaScript\PBZModLoader\generated-mods\
    ProjectPBZ\Content\JavaScript\PBZModLoader\generated-reloads\
    ProjectPBZ\PBZModLoader\compiler\
    ProjectPBZ\PBZModLoader\evidence\
    ProjectPBZ\PBZModLoader\TOOLCHAIN-LICENSE.txt
Keep the new bootstrap.js in ProjectPBZ\Content\JavaScript\PBZModLoader: it replaces the old one.
Keep ProjectPBZ\PBZModLoader\mods\ and your mods.ini.

UNINSTALL
Close the game. Delete the entry DLL of this loader (not another tool's), ProjectPBZ\Content\JavaScript\PBZModLoader\bootstrap.js,
and ProjectPBZ\PBZModLoader\LICENSES.txt and loader.log.
Your mods and mods.ini stay in ProjectPBZ\PBZModLoader until you delete them.

IF SOMETHING IS WRONG
Read ProjectPBZ\PBZModLoader\loader.log. "MODs skipped" means loader initialization failed. Read the reason that follows it.
Mods that depend on the loader may not work.
Without the entry DLL, the game runs as if the loader was never there.

PBZModLoader 安装说明
这是 KintaroModding 基于 LKF 的 PBZModLoader 的分支：https://github.com/KintaroModding/phantombladezero_pbzmodloader

安装
最简单的方式：在 MOD 管理器 UE MM 中一键安装：https://github.com/KintaroModding/uemodmanager

手动安装步骤如下：
1. 退出游戏，打开游戏安装目录（能看到 ProjectPBZ 文件夹的位置）。
2. 检查实际游戏 EXE 旁（platform\steam 或 platform\wegame）是否已有其他工具的 version.dll；如有，请勿覆盖，见下方“备用入口”。
3. 使用默认入口时，将 ProjectPBZ 复制到游戏安装目录，并将对应平台文件夹中的 version.dll 放到游戏 EXE 旁。
   如果 version.dll 属于其他工具，则只复制 ProjectPBZ，并按下方“备用入口”操作。不要复制压缩包中的 version.dll。
   正确：D:\Games\PBZ\ProjectPBZ；错误：D:\Games\PBZ\PBZModLoader\ProjectPBZ。
4. 从原游戏平台启动游戏即可。无需 Node.js、编译器或 UE4SS。

安装到游戏中的文件
- 游戏 EXE 旁的 version.dll：加载器，脚本已内置其中。
- ProjectPBZ\Content\JavaScript\PBZModLoader\bootstrap.js：启动文件。DLL 会用自己的脚本替换其内容。请勿修改或删除。
- ProjectPBZ\PBZModLoader\LICENSES.txt：许可证文本。
- ProjectPBZ\PBZModLoader\mods\：你的 MOD。
运行时加载器只写入一个文件：ProjectPBZ\PBZModLoader\loader.log，每次启动游戏时重新生成。

MOD
- 将整个 MOD 文件夹放入 ProjectPBZ\PBZModLoader\mods，例如 mods\my-mod\main.js。文件夹名即 MOD ID，只使用英文字母、数字、下划线或连字符。新 MOD 自动发现。
- MOD 必须提供 JavaScript。只有 main.ts 的 MOD 不会运行，loader.log 会说明原因。作者请用开发包编译 TypeScript。
- 修改游戏脚本的 pak MOD 同样可用：放在 ProjectPBZ\Content\Paks\~mods，无需其他工具。

MODS MENU
Mods Menu 0.9.0 或更高版本可与本加载器同时运行。请从其页面手动安装。它需要本加载器的启动文件：没有启动文件时，Mods Menu 不会启动。
两者同时安装时，Mods Menu 先启动它的 MOD，然后本加载器启动自己文件夹中的 MOD。
更早的 Mods Menu 版本会与本加载器冲突。Mods Menu 使用 hid.dll，因此请勿同时使用本加载器的 hid 入口。

设置（可选）
没有 ProjectPBZ\PBZModLoader\mods.ini 时，所有 MOD 都会加载。只有需要更改时才创建：
    [Loader]
    Version=1
    ; 0 表示关闭整个加载器。
    Enabled=1
    ; 0 表示拒绝修改游戏脚本的 pak MOD。
    AllowScriptPaks=1
    [Mods]
    ; my-mod=0 表示关闭单个 MOD。

热重载（Alt+F5）
保存文件后切回游戏按 Alt+F5，左上角显示约 4 秒提示。
加载器会应用 JavaScript MOD 列表及 [Mods] 设置的变化，包括新增和移除 MOD。此操作不会重载 pak MOD 或 UE4SS MOD。
MOD 必须导出 stop() 并在其中清除定时器和取消事件订阅。如果缺少 stop() 或清理失败，将保留现有实例，不加载新版本。
启动时失败的 MOD 在下次启动游戏前不会重试。日志中的 “reload complete” 表示本次重载操作已结束，不代表所有 MOD 都重载成功。
请检查各 MOD 的失败或跳过记录。约 4000 次重载后请重启游戏。

备用入口
如果其他工具占用了 version.dll，请保留它。本压缩包的 alternative-entries 中，hid.dll、winmm.dll、dsound.dll、dxgi.dll 各有一个文件夹。
不要把该文件夹解压到游戏中。选择一个 DLL，保持原文件名，放到游戏 EXE 旁。本加载器只安装一个入口。文件名未被占用不代表游戏会足够早地加载它：如果没有生成新的 loader.log，或日志为空，请尝试另一个入口。
更换前请退出游戏，并移除此前选用的本加载器 DLL。保留其他工具的 DLL。

从 2.0.x 更新
退出游戏，替换 DLL 和 LICENSES.txt，并添加启动文件：按上述方式将 ProjectPBZ 复制到游戏安装目录。
保留 ProjectPBZ\PBZModLoader\mods\ 和你的 mods.ini。

从 1.0.x 更新
按上述步骤操作，然后删除旧版本留下的内容（均可安全删除）：
    ProjectPBZ\Content\JavaScript\PBZModLoader\manager.js
    ProjectPBZ\Content\JavaScript\PBZModLoader\generated-config.js
    ProjectPBZ\Content\JavaScript\PBZModLoader\generated-mods\
    ProjectPBZ\Content\JavaScript\PBZModLoader\generated-reloads\
    ProjectPBZ\PBZModLoader\compiler\
    ProjectPBZ\PBZModLoader\evidence\
    ProjectPBZ\PBZModLoader\TOOLCHAIN-LICENSE.txt
保留 ProjectPBZ\Content\JavaScript\PBZModLoader 中新的 bootstrap.js：它会替换旧文件。
保留 ProjectPBZ\PBZModLoader\mods\ 和你的 mods.ini。

卸载
退出游戏，删除本加载器的入口 DLL（不要删除其他工具的 DLL）、ProjectPBZ\Content\JavaScript\PBZModLoader\bootstrap.js，
以及 ProjectPBZ\PBZModLoader\LICENSES.txt 和 loader.log。MOD 和 mods.ini 由你自行决定是否删除。

遇到问题
查看 ProjectPBZ\PBZModLoader\loader.log。“MODs skipped” 表示加载器初始化失败。请查看其后的具体原因。依赖此加载器的 MOD 可能无法正常运行。删除入口 DLL 后，游戏与未安装加载器时相同。
