PBZModLoader: install guide (English below, 中文在后)
This is the KintaroModding fork of PBZModLoader by LKF: https://github.com/KintaroModding/phantombladezero_pbzmodloader

INSTALL
1. Close the game. Open its install folder, the one that holds ProjectPBZ.
2. Look next to the real game exe (platform\steam or platform\wegame). If another tool already has a version.dll
   there, do not overwrite it: see ANOTHER ENTRY below.
3. Extract this zip into the install folder. Correct: D:\Games\PBZ\ProjectPBZ. Wrong: D:\Games\PBZ\PBZModLoader\ProjectPBZ.
4. Start the game from its platform as usual. You need no Node.js, no compiler and no UE4SS.

WHAT GOES INTO THE GAME
- version.dll next to the game exe: the loader, with its scripts inside.
- ProjectPBZ\PBZModLoader\LICENSES.txt: the license texts.
- ProjectPBZ\PBZModLoader\mods\: your mods.
While it runs, the loader writes one file: ProjectPBZ\PBZModLoader\loader.log. It starts new with each game start.

MODS
- Put the whole mod folder into ProjectPBZ\PBZModLoader\mods, for example mods\my-mod\main.js. The folder name is the mod's ID:
  English letters, digits, _ or - only. New mods are found by themselves.
- A mod must ship JavaScript. A mod with only main.ts does not run, and loader.log says so. Authors compile TypeScript with the
  developer package.
- Pak mods that change game scripts work too: keep them in ProjectPBZ\Content\Paks\~mods. They need no other tool.

SETTINGS (optional)
Without ProjectPBZ\PBZModLoader\mods.ini, every mod loads. Create the file only to change something:
    [Loader]
    Version=1
    ; 0 turns the whole loader off.
    Enabled=1
    ; 0 refuses pak mods that change game scripts.
    AllowScriptPaks=1
    [Mods]
    ; my-mod=0 turns one mod off.

RELOAD WHILE PLAYING (Alt+F5)
Save your files, return to the game and press Alt+F5. A message shows at the top left for about four seconds. All mods reload, also
new and removed ones and changes in [Mods]. A mod must export stop() and clean up its timers and events there; without stop() the
old copy stays, and that mod is skipped until the next game start. A mod that failed at its start is not tried again until then.
The log line "reload complete" confirms it. After about 4000 reloads, restart the game.

ANOTHER ENTRY
If another tool holds version.dll, keep it. Take one DLL from PBZModLoader-<version>-alternative-entries.zip (hid.dll, winmm.dll, dsound.dll,
dxgi.dll), keep its name, and put it next to the game exe. Install only one entry of this loader. A DLL file name that is free does not
prove that the game loads it early enough: if loader.log stays empty, try another one.

UPDATE FROM VERSION 1.0.0
Close the game, replace the DLL as above, and delete what the old version left, all of it safe to remove:
    ProjectPBZ\Content\JavaScript\PBZModLoader\
    ProjectPBZ\PBZModLoader\compiler\
    ProjectPBZ\PBZModLoader\evidence\
    ProjectPBZ\PBZModLoader\TOOLCHAIN-LICENSE.txt
Keep ProjectPBZ\PBZModLoader\mods\ and your mods.ini.

UNINSTALL
Close the game. Delete the entry DLL of this loader (not another tool's), and ProjectPBZ\PBZModLoader\LICENSES.txt and loader.log.
Your mods and mods.ini stay in ProjectPBZ\PBZModLoader until you delete them.

IF SOMETHING IS WRONG
Read ProjectPBZ\PBZModLoader\loader.log. "MODs skipped" means this game build is not supported yet: the game still runs, without mods.
Without the entry DLL, the game runs as if the loader was never there.


PBZModLoader 安装说明
这是 KintaroModding 基于 LKF 的 PBZModLoader 的分支：https://github.com/KintaroModding/phantombladezero_pbzmodloader

安装
1. 退出游戏，打开游戏安装目录（能看到 ProjectPBZ 文件夹的位置）。
2. 检查实际游戏 EXE 旁（platform\steam 或 platform\wegame）是否已有其他工具的 version.dll；如有，请勿覆盖，见下方“备用入口”。
3. 将本压缩包解压到游戏安装目录。正确：D:\Games\PBZ\ProjectPBZ；错误：D:\Games\PBZ\PBZModLoader\ProjectPBZ。
4. 从原游戏平台启动游戏即可。无需 Node.js、编译器或 UE4SS。

安装到游戏中的文件
- 游戏 EXE 旁的 version.dll：加载器，脚本已内置其中。
- ProjectPBZ\PBZModLoader\LICENSES.txt：许可证文本。
- ProjectPBZ\PBZModLoader\mods\：你的 MOD。
运行时加载器只写入一个文件：ProjectPBZ\PBZModLoader\loader.log，每次启动游戏时重新生成。

MOD
- 将整个 MOD 文件夹放入 ProjectPBZ\PBZModLoader\mods，例如 mods\my-mod\main.js。文件夹名即 MOD ID，只使用英文字母、数字、下划线或连字符。新 MOD 自动发现。
- MOD 必须提供 JavaScript。只有 main.ts 的 MOD 不会运行，loader.log 会说明原因。作者请用开发包编译 TypeScript。
- 修改游戏脚本的 pak MOD 同样可用：放在 ProjectPBZ\Content\Paks\~mods，无需其他工具。

设置（可选）
没有 ProjectPBZ\PBZModLoader\mods.ini 时，所有 MOD 都会加载。只有需要更改时才创建：
    [Loader]
    Version=1
    ; 0 表示关闭整个加载器。
    Enabled=1
    ; 0 表示拒绝修改游戏脚本的 pak MOD。
    AllowScriptPaks=1
    [Mods]
    ; my-mod=0 表示关闭单个 MOD。

热重载（Alt+F5）
保存文件后切回游戏按 Alt+F5，左上角显示约 4 秒提示。所有 MOD 都会重载，包括新增、删除的 MOD 和 [Mods] 的变化。MOD 必须导出 stop() 并在其中清理定时器和事件；
缺少 stop() 时旧实例保留，该 MOD 在下次启动前被跳过。启动时失败的 MOD 在下次启动前不会重试。日志中的 “reload complete” 表示完成。约 4000 次重载后请重启游戏。

备用入口
如果其他工具占用了 version.dll，请保留它。从 PBZModLoader-<版本>-alternative-entries.zip 中选择一个 DLL（hid.dll、winmm.dll、dsound.dll、dxgi.dll），
保持原文件名，放到游戏 EXE 旁。本加载器只安装一个入口。文件名未被占用不代表游戏会足够早地加载它：如果 loader.log 没有内容，请换一个。

从 1.0.0 更新
退出游戏，按上述方式替换 DLL，然后删除旧版本留下的内容（均可安全删除）：
    ProjectPBZ\Content\JavaScript\PBZModLoader\
    ProjectPBZ\PBZModLoader\compiler\
    ProjectPBZ\PBZModLoader\evidence\
    ProjectPBZ\PBZModLoader\TOOLCHAIN-LICENSE.txt
保留 ProjectPBZ\PBZModLoader\mods\ 和你的 mods.ini。

卸载
退出游戏，删除本加载器的入口 DLL（不要删除其他工具的 DLL），以及 ProjectPBZ\PBZModLoader\LICENSES.txt 和 loader.log。MOD 和 mods.ini 由你自行决定是否删除。

遇到问题
查看 ProjectPBZ\PBZModLoader\loader.log。“MODs skipped” 表示尚不支持当前游戏版本：游戏仍可运行，但不加载 MOD。删除入口 DLL 后，游戏与未安装加载器时相同。
